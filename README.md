# 🛒 Shopping Cart System

## Overview  
A simple **shopping cart system** implemented in **C++** that allows users to add products to a cart and view the total price.

## Features  
✅ Object-oriented design using **classes**  
✅ **Add products** to the shopping cart  
✅ **Display cart details**, including price and quantity  
✅ **Calculate the total price** of all items  

## Technologies Used  
- C++ (Standard Library: `<vector>`, `<iostream>`)  

## Installation & Usage  
```bash
# Clone the repository
git clone https://github.com/your-username/shopping-cart-cpp.git

# Navigate to the project directory
cd shopping-cart-cpp

# Compile the code
g++ shopping_cart.cpp -o shopping_cart

# Run the program
./shopping_cart
```
